INK / 规范 CH 05 · VOICE & MOTION

语气与动效。
先感受，再解释。

语气决定被不被信任，动效决定变化被不被理解。两者都在做同一件事：让界面像人说话，而不是像系统通知。

01 / VOICE

语气

短句、动词具体、不吓人、给出下一步。不用敬语堆叠，也不用感叹号撑情绪；轻松不等于随便。

操作按钮

✓推荐：开始吧

✕避免：立即开始体验

出错提示

✓推荐：这里没填对，再试一次

✕避免：操作失败（错误码 400）

空状态

✓推荐：这里还空着，来写第一笔

✕避免：暂无数据

确认危险操作

✓推荐：删掉这两段？删了就找不回来。

✕避免：确认删除？

一句话只做一件事。解释原因的句子，不要顺手加操作；要求操作的句子，先给后果。用户读不完第二行。
02 / TIMING

时长与缓动

动效只解释变化：从哪里来、去了哪里、什么被替换。它不负责添加气氛，也不负责让人「哇」。

时长刻度
场景 时长 缓动 变量
悬停反馈200ms快出、轻收--ink-duration-hover
按下确认140ms到位即停--ink-duration-press
空间展开380ms带一点吸附感--ink-duration-expand
页面进入420ms减速收尾--ink-duration-page
同组依次进入+45ms / 项不叠加抖动--ink-stagger
SNAP / 吸附

cubic-bezier(0.17, 0.89, 0.32, 1.18)

用于空间展开与回到原处。轻微过冲，让「展开」有物理感；幅度只允许这一档。

EASE / 收放

ease-in · ease-out

悬停与按下用 ease-in（快速回应，缓慢收住）；退场和页面进入用 ease-out（先快后慢，不拖尾）。

不做滚动劫持，不做视差。页面滚动永远由用户控制；需要讲长故事时，用章节，不用滚动坐标。不做无限循环的装饰动画，也不做「惊喜」式动效。
03 / CONTINUITY

空间连续性

面板从触发它的位置展开，关闭时回到原处；底层页面不换、不滚、不清空，焦点在关闭后回到触发元素。这是这套语言里唯一允许「炫」的地方。

点开下面的按钮：注意面板从哪里长出来，关闭时又回到哪里。

去首页彩蛋 →

使用原生 <dialog> + Web Animations API；Esc、遮罩点击、关闭按钮三种方式返回，焦点自动回到触发处。

04 / A11Y

降级与无障碍

动效是增强，不是功能。关掉动画，功能一个不少；键盘用户不用碰到鼠标，也能完成同一件事。

✓ DO / 这样做

所有过渡与动画都在 prefers-reduced-motion 下降为 0ms。

焦点环始终可见：2px 墨色描边、外扩 4px。

打开对话框后焦点进入面板；关闭后回到触发元素。

提供 .visually-hidden 文案给屏幕阅读器，不用占位文字代替标签。

✕ DON'T / 不要这样

不要在 focus 时移动元素，焦点需要稳定。

不要只用颜色表示选中或错误状态。

不要让动画阻塞交互；动效结束前按钮必须仍可点。

不要用自动播放的循环动画吸引注意。

05 / TOKENS

变量

时长、缓动、位移幅度都是变量。改一处，全站一起变——这也是给 Agent 用的原因之一。

tokens.css · 动效 
--ink-ease-in: cubic-bezier(0.1, 0.9, 0.2, 1);
--ink-ease-out: cubic-bezier(0.7, 0, 1, 0.5);
--ink-ease-snap: cubic-bezier(0.17, 0.89, 0.32, 1.18);

--ink-duration-hover: 200ms;
--ink-duration-press: 140ms;
--ink-duration-expand: 380ms;
--ink-duration-page: 420ms;
--ink-stagger: 45ms;

--ink-hover-lift: -3px;
--ink-press-scale: 0.975;

@media (prefers-reduced-motion: reduce) {
  :root {
    --ink-duration-hover: 0ms;
    --ink-duration-press: 0ms;
    --ink-duration-expand: 0ms;
    --ink-duration-page: 0ms;
    --ink-stagger: 0ms;
    --ink-hover-lift: 0px;
    --ink-press-scale: 1;
  }
}
