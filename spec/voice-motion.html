05 / 文案与动效

把句子写短

文案先给动词和数字；动效解释位置变化，不表演。悬停 200ms，展开 380ms，收起 240ms。

200 / 140 / 380 / 240 / 420ms

01 / 文案

四类句子，一种写法

动词开头，写清对象和数字。出错时写清哪一项、错在哪、下一步做什么。

按钮
推荐动词加对象

保存修改

说明按下去会发生什么，对象是哪个。

避免只有流程名

提交

用户要猜提交什么、提交到哪。

出错
推荐字段、格式、例子

金额需要填数字，例如 128。

一句话写完哪一项错、正确格式是什么。

避免感叹号加重语气

输入有误！

没说哪一项错，也没给下一步。

空状态
推荐说明现状和入口

还没有记录。新建一条，从这里开始。

现状一句，下一步一句。

避免系统词收尾

暂无数据

用户不知道是该等，还是该做什么。

危险操作
推荐后果、对象、数量

删除后无法恢复。确认删除这 3 条记录？

写明删了找不回来，以及删的是哪几条。

避免只问确认

确定要删除吗？

没写删了会怎样，也没写影响几条。

02 / 时长与缓动

六档时长，三条曲线

悬停只改颜色，展开解释位置。最长一档 420ms。

六档时长，全部来自 tokens.css
场景 时长 变量 用在哪
悬停200ms--ink-duration-hover底色与文字颜色的渐变
按下140ms--ink-duration-press按钮缩到 0.975
展开380ms--ink-duration-expand面板从触发点展开
收起240ms--ink-duration-collapse面板缩回触发点
页面切换420ms--ink-duration-page整页与章节首屏进入
依次进入+45ms / 项--ink-stagger同组元素错开出场

三条曲线：ease-in cubic-bezier(0.1, 0.9, 0.2, 1)，ease-out cubic-bezier(0.7, 0, 1, 0.5)，snap cubic-bezier(0.17, 0.89, 0.32, 1.18)。只动 transform 和 opacity，不动宽高与 top/left。

03 / 空间连续性

从哪来，回哪去

面板从触发按钮的矩形中心展开，关闭时缩回原处。页面不换、不滚。

Esc、点面板外、点「回到原处」三条路都能退出。关闭后焦点回到触发按钮，阅读位置不变。

04 / 无障碍

系统设置优先，键盘能走完

减少动态时所有时长归 0；键盘能打开、能操作、能回到原处。

减少动态
推荐跟随系统设置

prefers-reduced-motion: reduce 时，六档时长与 stagger 全部归 0。

浮层直接出现在最终位置，不做位移；内容与可见状态不依赖动画。

避免忽略系统设置

用户已经要求减少动态，页面照常播放展开和位移。

前庭敏感的人被迫承受缩放与移动。

键盘
推荐焦点可见、顺序清楚

焦点环 2px 墨色、外扩 4px，Tab 顺序与阅读顺序一致。

Esc、遮罩、关闭按钮三条路都能退出，关闭后焦点回到触发按钮。

避免只能点鼠标

交互只响应鼠标点击，关闭后焦点丢失。

键盘用户找不到当前位置，也回不到打开前的元素。

05 / 变量

时长和曲线都在 tokens.css

脚本从 getComputedStyle 读取时长；页面和 JS 都不写毫秒数。

tokens.css / 动效 
:root {
  /* 缓动：进入、退出、展开 */
  --ink-ease-in: cubic-bezier(0.1, 0.9, 0.2, 1);
  --ink-ease-out: cubic-bezier(0.7, 0, 1, 0.5);
  --ink-ease-snap: cubic-bezier(0.17, 0.89, 0.32, 1.18);

  /* 六档时长 */
  --ink-duration-hover: 200ms;
  --ink-duration-press: 140ms;
  --ink-duration-expand: 380ms;
  --ink-duration-collapse: 240ms;
  --ink-duration-page: 420ms;
  --ink-stagger: 45ms;

  /* 位移与按下 */
  --ink-shift: 6px;
  --ink-press-scale: 0.975;
}

/* 用户要求减少动效时，全部归零 */
@media (prefers-reduced-motion: reduce) {
  :root {
    --ink-duration-hover: 0ms;
    --ink-duration-press: 0ms;
    --ink-duration-expand: 0ms;
    --ink-duration-collapse: 0ms;
    --ink-duration-page: 0ms;
    --ink-stagger: 0ms;
    --ink-shift: 0px;
    --ink-press-scale: 1;
  }
}

空间连续性

一块面板

从按钮的矩形中心展开，关闭时缩回按钮。三条退出路径都回到同一个位置。

01 起点 量出触发按钮的中心点与宽高，作为展开动画的起点。
02 展开 380ms 从按钮位置放大到面板位置，缓动用 snap。
03 返回 240ms 缩回按钮；Esc、遮罩、关闭按钮都走这条路径。
