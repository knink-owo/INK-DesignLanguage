INK / 规范 CH 03 · SPACE

空间。
留白是内容，不是没填满。

INK 的克制不靠少写，靠排得开。间距是节奏，网格是纪律；圆角为零，直角让每个区块站得更稳。

01 / SCALE

十级间距

从 4px 到 128px，每一级只有一个变量可用。页面里不出现裸间距值；需要更细的间隔时，用行高而不是间距。

02 / GRID

页面网格

内容区最大 1200px，左右留 clamp(20px, 5vw, 64px)。移动端单列，桌面端最多六列；列间距恒为 16px。

WRAP / 内容区

1200 px

--ink-wrap

GUTTER / 左右留白

20–64 px

clamp(20px, 5vw, 64px)

HEADER / 顶栏高

64 px

--ink-header-h

圆角恒为 0。所有面板、按钮、输入框、对话框都是直角。直角不是冷，是让内容对齐时有明确的边；需要柔和时，用留白，不用圆角。
03 / RHYTHM

节奏

一屏只主张一件事。主张之后，用 48–96px 的空白让读者喘口气，再进入下一件事。

SECTION / 章节

章标题与引言之间 16px；引言与第一个模块之间 32–48px；模块之间 48–64px；章节之间 96px 起。

规则简单到可以背下来：越大的东西，离它上面的东西越远。

DENSITY / 密度

信息越密，越要靠行高和分组，而不是压缩间距。表格用 12px 内边距，正文用 24px 段距。

页面允许空。空的地方不是待填的坑，是让前面那句话被听见的停顿。

04 / BREAKPOINTS

断点

只有两个断点，都按内容拥挤程度决定，不按设备名。980px 收窄网格，680px 收成单列。

响应式行为
断点 变化 不变
< 980px 色场从 8 列变 4 列；三栏变一栏；章节头从双栏变单栏。 字号阶梯、间距刻度、圆角与边框。
< 680px 双栏、三栏、六栏全部单列；顶栏隐藏「给 Agent」；色场 2 列。 正文不小于 16px；触控目标不小于 44px。
