INK / 规范 CH 04 · COMPONENTS

组件。
方角，清晰的边，一层就够。

INK 的组件没有第二套皮肤。按钮、输入框、面板共用同一套语法：直角、1px 线、纸白底；深度只给需要浮起来的少数东西。

01 / GRAMMAR

视觉语法

三条就够了：边界用 1px 线，不用阴影；圆角恒为 0；需要浮起时，只允许一层投影，且只给对话框与悬浮面板。

EDGE / 边

1px

默认线色 --ink-line，强调线用墨黑。所有边界都是实线，不用虚线分割内容。

RADIUS / 圆角

0px

按钮、输入框、面板、对话框，全部直角。没有胶囊按钮，也没有圆角卡片。

ELEVATION / 深度

1 层

页面本身不用阴影；--ink-shadow-2/3/4 只给悬浮底色、抽屉与对话框。

02 / BUTTONS

按钮

只有三种按钮：深墨主按钮、描边次按钮、湖蓝色场按钮。主按钮一屏一个；色场按钮一屏最多一个；其余动作降级为链接。

从左到右：主操作 · 次操作 · 色场操作 · 禁用。按钮最小高度 44px，内边距 24px，字重 600。

✓ DO / 这样做

用动词开头：「开始吧」「返回原处」「复制」。

一屏一个主按钮；两个主按钮等于没有主按钮。

按下时缩到 0.975，不改变阴影或颜色。

✕ DON'T / 不要这样

不要「立即开始体验」这类自夸式文案。

不要胶囊形、圆角或渐变按钮。

不要用色场颜色区分按钮的主次；主次只由实心与描边区分。

03 / FIELDS

输入

输入框是唯一允许使用 1px 边框 + 纸白底 + 44px 高度的零件。标签在上，提示在下，错误就地说清楚怎么改。

只用它发送更新，不发广告；随时可以退订。

这里没填对，再试一次：验证码是 6 位数字。

聚焦时出现 2px 墨色描边并外扩 2px；错误用胭脂色边框，但错误信息必须写出下一步。

04 / SURFACES

面板与入口

面板是最小的内容容器：1px 线、纸白底、24px 内边距。整块可点击时变成入口——悬停抬高 3px，只有一层投影。

CH 01 色彩 八个色场与四个中性色。 CH 02 文字 字号阶梯与中英混排。
SURFACE / 面板

不可点击的内容用面板，可点击的入口用入口块。两者视觉相同，只在悬停与 <a> 语义上不同。

05 / LABELS

标签

标签只有两种：灰底等宽的「键」，与深墨反白的「牌」。键用来标注变量和版本，牌用来标注状态，都只有一行字。

--ink-space-4 CH 04 · COMPONENTS INK V1.0

键：纸白底、1px 线、等宽字、次要色。牌：墨黑底、白字、全大写小号字。两者都不带圆角。

06 / TOKENS

变量

深度、边框、焦点、触控目标都从变量取。组件样式集中在 assets/site.css，不散落在页面里。
