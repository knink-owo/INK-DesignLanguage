04 / 组件

方角和一条线

圆角恒 0，边线 1px，投影只给浮层。按钮 44px 高、内距 24px、悬停 200ms。

0 圆角 / 1px 边线 / 44px 触控

01 / 按钮

四种按钮，一套尺寸

高度 44px，左右内距 24px，边线 1px。主按钮做唯一主操作，其余动作降级。

看一眼色彩

主按钮一屏只放一个；按下缩到 0.975，140ms 回弹。

02 / 表单

标签在上，错误在下

输入框用纯白底与 1px 次要灰边。错误就地写清哪一项、错在哪。

只用于回复，不共享。

验证码是 6 位数字，再试一次。

错误文案说清问题和下一步，不用感叹号。

03 / 表面

整块可点时，整块是入口

入口块 1px 墨色边线，整块可点。悬停时底色转墨，文字转纸白。

规范 01 / 色彩 八个色场与八组中性色 → 规范 05 / 文案与动效 六档时长与三条返回路径 →

浮层阴影只用一个 token：--ink-shadow-modal。其余表面用 1px 细线分层，不加投影。

04 / 标签

状态用 chip，分类用 tag

两种标签都 28px 高、圆角 0。chip 纸白带线，tag 深墨反白。

进行中 已发布 V1.1

状态用 chip，分类用 tag，不加圆角。

05 / 变量

改尺寸只改 tokens.css

页面不写裸值。几何、阴影、层级和按下反馈都在这一段。

tokens.css / 几何与浮层 
:root {
  /* 几何：圆角恒 0，描边恒 1px */
  --ink-radius: 0;
  --ink-target: 44px;
  --ink-border: 1px solid var(--ink-line);
  --ink-border-strong: 1px solid var(--ink-ink);

  /* 浮层：只有这一层阴影 */
  --ink-shadow-modal: 0 32px 80px rgba(27, 36, 31, 0.24),
    0 2px 8px rgba(27, 36, 31, 0.08);
  --ink-z-header: 20;
  --ink-z-modal: 60;

  /* 按下：缩到 0.975，140ms 回弹 */
  --ink-duration-press: 140ms;
  --ink-press-scale: 0.975;
}
