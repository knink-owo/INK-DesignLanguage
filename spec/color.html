01 / 用法

色场用来分类，强调用字重和留白

色场是版面上的分区标记。需要强调时，加粗标题或加大留白，不动颜色。

推荐深墨字放在色场上

湖蓝底 + #16211D 文字

八块色场对深墨的对比度在 6.1 到 8.1 之间，16px 正文和更小的字都够用。

避免白字放在色场上

湖蓝底 + 白色文字

白字对色场只有 2.0 到 2.7:1，任何字号都不合格。需要反白时，改用深墨 #1B241F 底。

02 / 中性色

八组中性色，各有分工

页面底色始终是纸白，纯白只给输入框和浮层。文字只用墨和两档灰。

纸白 #FAF9F5 页面底色。不用纯白做底。
纯白 #FFFFFF 只给输入框、浮层这类需要浮起来的表面。
墨 #26302C 正文、标题、边线。对纸白 12.9:1。
深墨 #1B241F 页脚、代码块、反白区域。对白字 13.6:1。
次要灰 #5E6A64 说明文字、次要信息。对纸白 5.36:1。
弱化灰 #8B948E 只用于线、图标或 24px 以上大字。对纸白 2.96:1。
细线 #E5E8E1 1px 分隔线。全站只用这一种线。
色场字 #16211D 只出现在色场上。不用纯黑。
03 / 硬规则

冲突时按这个顺序处理

先删掉多余的色场，再用中性色分层，最后才考虑加新颜色。

01 / 一屏一块

一屏只出现一块色场

同屏出现两块时删掉一块，第二块放到下一屏或下一章。色场相邻时，用 1px 细线分开。

02 / 只用深墨

色场里只放深墨文字

白字对色场最多 2.7:1。需要反白时换成深墨 #1B241F 底，那里是 13.6:1。

03 / 不加色相

不新增颜色

需要更多层级时，用纸白、纯白、墨、深墨、两档灰和细线。加渐变、加投影色都不算新层级。

04 / 变量

改色只改 tokens.css

页面和组件里不写色值。下面这段可以从这里复制，也可以直接读文件。

tokens.css / 色场与中性色 
:root {
  /* 色场：八个，各管一类信息 */
  --ink-lake:   #6EA8A3;
  --ink-sky:    #87B9CE;
  --ink-moss:   #8FB394;
  --ink-lotus:  #A995C4;
  --ink-wheat:  #D2B173;
  --ink-clay:   #CE927C;
  --ink-stone:  #94A7B0;
  --ink-rouge:  #C98D9B;

  /* 中性色 */
  --ink-canvas:        #FAF9F5;
  --ink-surface:       #FFFFFF;
  --ink-ink:           #26302C;
  --ink-ink-deep:      #1B241F;
  --ink-ink-secondary: #5E6A64;
  --ink-ink-muted:     #8B948E;
  --ink-line:          #E5E8E1;
  --ink-text-on-color: #16211D;
}
