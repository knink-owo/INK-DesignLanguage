INK / 规范 CH 01 · COLOR

色彩。
八个色场，一次只让一个说话。

INK 的底色是纸白，声音来自八个色场。它们不是调色盘，是八个可以站进去的「区块」；一屏之内，通常只允许一个色场开口。

01 / PALETTE

八个色场

每个色场只承担一种角色，六位十六进制、零渐变。色场是「这段属于哪个领域」的标记，不是装饰，不是重要性排序。

湖蓝 Lake #6EA8A3 rgb(110 168 163)
界面中最常出现的中间音。链接、主操作、静默的强调都归它—它不抢眼，但每页都有它。 --ink-lake
天青 Sky #87B9CE rgb(135 185 206)
信息与说明。比湖蓝更轻，用在补充说明和流程提示，避免被误认为操作。 --ink-sky
苔绿 Moss #8FB394 rgb(143 179 148)
完成与通过。只表达「事情成了」；不表达「继续」—继续用深墨按钮。 --ink-moss
藕荷 Lotus #A995C4 rgb(169 149 196)
创作与草稿。用户正在写、还没定稿的内容；正式结果不要用它。 --ink-lotus
麦金 Wheat #D2B173 rgb(210 177 115)
标记与他人。高亮、批注、被提及；一屏只出现一处。 --ink-wheat
陶土 Clay #CE927C rgb(206 146 124)
提醒与受阻。不是错误：错误用胭脂，提醒用陶土。 --ink-clay
石灰 Stone #94A7B0 rgb(148 167 176)
系统与工具。导航外壳、元信息、被折叠的次要区域。 --ink-stone
胭脂 Rouge #C98D9B rgb(201 141 155)
错误与危险。只在需要用户停手时出现；出现后必须给出下一步。 --ink-rouge
一个色场，一次发言。同一屏里两个色场并列出现，等于两段话同时提高音量。需要并列时，用纸白隔开，或者改用文字层级。
02 / NEUTRALS

四个中性色

中性色负责承重。纸白是底，面白是卡片，墨黑是正文与主按钮，深墨是色场上的字。没有纯黑，也没有纯白。

纸白 Canvas

--ink-canvas · #FAF9F5

默认页面底色。比纯白柔和一档，长时间阅读不刺眼。

面白 Surface

--ink-surface · #FFFFFF

卡片与面板。只靠它和纸白之间的一层界线区分，不靠阴影。

墨黑 Ink

--ink-ink · #26302C

正文与主按钮背景。不是纯黑，保留一点绿灰。

深墨 On color

--ink-text-on-color · #16211D

色场上的文字。与八个色场的对比度都在 6:1 以上，不要用白色压亮色块。

03 / RULES

怎么用，怎么不用

颜色只回答「这段属于什么」，不回答「这有多重要」。重要性交给留白、字号和位置——这些是文字层面的决定，颜色不该越权。

INFO / 说明

这一段是补充说明。它不该看起来像按钮，所以用天青，而不是湖蓝。

FIELD IN USE

色场可以包住一段话，但不改变它的角色。色场越大，里面的字越要克制。

✓ DO / 这样做

一屏一个色场；色场之间隔纸白。

正文永远用墨黑；色场只做区块身份。

色场上的字用深墨 #16211D，不用白色。

一个按钮系统：深墨主按钮 + 湖蓝色场按钮，各一个。

✕ DON'T / 不要这样

不要白字压亮色块，也不要给色块加深色叠层来「救」可读性。

不要把八个色当成同一层的调色盘混着用。

不要用渐变、圆角或阴影修饰颜色。

不要用颜色表达重要性。

04 / TOKENS

变量

全部颜色只从 tokens.css 取。页面里不写裸色值；确需一次性色块时才允许内联变量。

tokens.css · 色彩 
:root {
  /* 八个色场 */
  --ink-lake: #6EA8A3;    /* 湖蓝 · 主强调 */
  --ink-sky: #87B9CE;     /* 天青 · 信息 */
  --ink-moss: #8FB394;    /* 苔绿 · 积极 */
  --ink-lotus: #A995C4;   /* 藕荷 · 创作 */
  --ink-wheat: #D2B173;   /* 麦金 · 提醒 */
  --ink-clay: #CE927C;    /* 陶土 · 活动 */
  --ink-stone: #94A7B0;   /* 石灰 · 中性 */
  --ink-rouge: #C98D9B;   /* 胭脂 · 错误 */

  /* 中性色 */
  --ink-canvas: #FAF9F5;
  --ink-surface: #FFFFFF;
  --ink-ink: #26302C;
  --ink-ink-secondary: #5E6A64;
  --ink-line: #E5E8E1;

  /* 语义别名 */
  --ink-text-primary: var(--ink-ink);
  --ink-text-secondary: #5E6A64;
  --ink-text-on-color: #16211D;
  --ink-text-on-ink: #FFFFFF;
}
