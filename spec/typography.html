02 / 文字

先把一句排好

系统字体、七级字号、中文行距。正文 16px 起，行高 1.75，每行 30 到 45 个汉字。

3 个字体角色 / 7 级字号 / 正文 16px 起

01 / 字体

三个角色，两套字体栈

展示、正文、等宽各占一行。展示和正文共用一套系统无衬线，靠 600 与 400 两档字重分开。

展示--ink-font · 600
八色场 Aa
正文--ink-font · 400
留白按刻度走，字号按阶梯落。
等宽--ink-font-mono · 400
tokens.css

全部用系统字体，不下载字体文件。macOS 落苹方，Windows 落微软雅黑。

03 / 排中文

中英之间留空格，标点用全角

中文句子里，西文前后空一格；中文标点占全角，数字用半角。正文列宽控在一行 30 到 45 个汉字。

推荐中英之间留空格

用 tokens.css 管理 8 个色场。

空格加在汉字与西文字符之间，行首和行尾不加。中文标点用全角。

避免中英文挤在一起

用tokens.css管理8个色场,一行80字。

空格缺失，半角逗号混进中文句子。读到数字和西文时要停下来断句。

推荐一行 30–45 个汉字

正文按 34em 折行，一行落 30 到 45 个汉字。

列宽与行高一起定：行高 1.75，换行时眼睛接得住下一行开头。

避免一行 80 字

正文拉到整屏宽，一行 80 字。

行尾离行首太远，换行容易串行。正文收进 34em。

正文列宽 34em，行高 1.75。两项都在 tokens.css 里定值。

04 / 变量

字号、行高、字距只改这里

页面里不写字号和行高。下面这段从 tokens.css 复制，改值先改源文件。

tokens.css / 字体与字号 
  /* 字体 */
  --ink-font: -apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC",
    "HarmonyOS Sans SC", "Noto Sans SC", "Microsoft YaHei", sans-serif;
  --ink-font-mono: "Cascadia Code", "SFMono-Regular", Consolas,
    "Liberation Mono", monospace;

  /* 字重与字号 */
  --ink-weight-body: 400;
  --ink-weight-display: 600;
  --ink-weight-strong: 600;

  --ink-size-display: clamp(3.25rem, 8vw, 7.5rem);    /* 52 → 120px */
  --ink-size-h1: clamp(2.75rem, 6vw, 5.5rem);         /* 44 → 88px */
  --ink-size-h2: clamp(2rem, 3.2vw, 2.75rem);         /* 32 → 44px */
  --ink-size-h3: clamp(1.375rem, 1.8vw, 1.75rem);     /* 22 → 28px */
  --ink-size-lead: clamp(1.125rem, 1.4vw, 1.375rem);  /* 18 → 22px */
  --ink-size-body: 1rem;
  --ink-size-small: 0.875rem;
  --ink-size-mono: 0.75rem;
  --ink-size-label: 0.6875rem;

  --ink-leading-display: 1;
  --ink-leading-heading: 1.14;
  --ink-leading-body: 1.75;
  --ink-tracking-display: -0.035em;
  --ink-tracking-label: 0.14em;
  --ink-stroke-display: 2px;

字重只有 400 和 600 两档。标题用 600，正文用 400。
