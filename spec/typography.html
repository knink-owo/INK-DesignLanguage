INK / 规范 CH 02 · TYPOGRAPHY

文字。
让句子先站稳，再谈风格。

INK 不用付费字体，也不做字体特效。系统字体、轻展示字重、克制的字号阶梯——文字的好看，来自它被读得下去。

01 / FONTS

三个角色，一套系统字体

正文、展示、等宽各有一组系统字体栈。零网络请求、零字体加载抖动；在 Mac、Windows、Linux 上都落在最接近的产品字上。

03 / MIXED TYPE

中英混排与标点

中文为主、西文为客。客人进来要留座：中英文之间空半个字符，标点各用各的体系。

SPACING / 空格

中文与英文、数字之间空一个半角空格。

✓ 在 INK 里，留白是内容。

✕ 在INK里，留白是内容。

PUNCTUATION / 标点

中文句子用全角标点；数字和英文用半角。破折号两个全角，省略号六个点。

✓ 先感受——再解释……就这样。

✕ 先感受--再解释...就这样.

标题断行按语义。用 <br> 或受控宽度断开完整意思，不让浏览器在词中间硬折。中文标题尤其不要出现孤字成行。
04 / READABILITY

可读性红线

风格可以让位，可读性不让。以下几条是尺寸与排版的硬约束，写进代码，也写进 review。

✓ DO / 这样做

正文 16px 起，中文行高不低于 1.75。

阅读列控制在 30–45 个汉字，约 34em。

展示字重 300 只用在 32px 以上的标题。

用字号、留白区分层级，不用颜色。

✕ DON'T / 不要这样

不要一屏混用三种以上字号。

不要给中文加伪斜体或全大写变形。

不要用渐变、描边、阴影处理文字。

不要把正文放在色场上，除非对比度经过计算。
